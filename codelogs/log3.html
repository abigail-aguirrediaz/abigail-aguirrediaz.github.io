Code Log 3: CSS Media Queries

Intro to CSS Media Queries

To learn about CSS Media Queries I believe the defintion given by the article "A Practical Guide to CSS Media Queries" explains in detail what this even is. The definiion is as follows, "allow you to style multiple versions of a single site depending on the type of device on which the layout/site is being viewed. In other words, they are constructs that allow you to specify, based on certain conditions,which styles should be used on a web page and which should not." So now how does it work and why is it useful?

CSS media queries are very useful and helpful with layouts, specifically one that will adapt well in the different size screens. The way this works is starting with a viewport level meta tag. This is what basically works as the communicator between the layout area and device width. This helps equally display the screne resolution on all devices.

What "media features" are supported by media queries and what do they do?

4 media media features that support media queries are width, hight, orientation, and resolution. The width allows you to condition that the viewport’s width is equal to a certain value. The height helps set conditions on the viewport height. The orientation helps set certain styles that can vary by the site display. Lastly, resolution helps with certain characteristic styles depending on the device’s pixel density.
