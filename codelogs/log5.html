Code Log 5: Images

What are the differences between presenting an image using an HTML tag and presenting it as the background of an HTML element (using the CSS property background-image)?

The differnce between using an HTML tag would be that in this case, the image is being embedded as content to the page itself. The article "HTML Images" gives us an example of how this tag would look like.

Ultimatly, this tag would require two attributes to be useful which are "src" and "alt". While in contrast using the CSS property would be used to place an image in the background of the content and or web page. This would mean this is part of the layout itself rather than the content being placed. With that, we also don't need the "alt" text. An example of this in code is shown in the website titled "CSS Background Property".

Another example for an HTML and CSS image tags would be one we just used for some previous projects. The first example showsm the HTML tag and the second one is from a differenet project that used in image in CSS.

Besides background-image, what other CSS properties affect the display of background images? Describe at least two more CSS properties.

Two other CSS properties that affect the display of backgroung images would be background color and background size. The background color sets the background color of an element and the background size affects the size of the image in the background and its scale.
